# Android 应用下载

本仓库发布逐词卡和专注守护的安装包及应用内更新附件。

## 专注守护 Android app

[下载专注守护 v1.0.5](https://github.com/julibeian/wordcards-releases/releases/tag/focusguard-v1.0.5)，支持 Android 8.0 及以上版本，全中文界面。

- 只有专注一种模式，学习、工作、阅读等事项可分别建立任务卡，自定义名称和时长（不限制或 1–180 分钟）。
- 点击任务的“开始”进入对应的独立专注页，显示任务名称和计时，可暂停、继续或结束；重新打开应用仍回到正在进行的任务。
- 主页任务卡更紧凑；今日专注、完成次数与应用使用时长的统计卡移到“数据”页，保留七天趋势、三十天热力图和最近记录。
- 专注期间拦截分心清单中的应用及通知，电话、闹钟和系统必需功能保持可用；支持每日应用限额与紧急临时放行。
- 升级保留自定义任务、历史记录、分心清单和每日限额。移除原来的禅定、休息及模式切换；旧专注计时与暂停状态继续恢复，已移除模式的进行中会话保存为中断。
- 首次在“设置”开启使用情况访问、无障碍应用拦截和通知使用权。Android 13 及以上若无障碍开关受限，请先在系统应用信息右上角允许受限设置。
- 在“设置 → 应用更新”检查新版，支持差分还原、断点续传、文件与签名校验及系统安装确认。记录仅保存在本机，不读取屏幕文字或聊天内容，无需账号。

专注守护使用独立的 `focusguard-latest/FocusGuard-update.json` 更新通道。逐词卡原来的 latest 更新入口继续保留。普通 Android 应用不具备厂商系统级的强制锁定权限。

## 逐词卡Android app

逐词卡app的应用下载和更新仓库。

### 安装

在 [最新版本](https://github.com/julibeian/wordcards-releases/releases/latest) 下载。支持 Android 8.0 及以上版本。


### 更新

在背词页底部点 **应用更新** 可立即联网确认；更新页内也有“立即检查更新”。默认每天自动检查一次，也可以关闭自动检查。

- 手动检查后有新版本会立即自动下载；网络中断时从已下载的位置续传，反复中断会提示稍后继续，不会从头重下。没有新版本时显示“无更新”。
- 有与当前安装包精确匹配的差分包时，优先下载差分包。
- 词典和图片没有变化时，复用其压缩内容，只下载变化部分。
- 应用将差分包还原为完整新版 APK，校验大小、SHA-256、应用包名、版本号和原签名后，再交给 Android 系统安装。
- 找不到匹配的差分包时显示完整包下载大小；差分失败后可重试或手动选择完整包。

查词和自查离线使用。网络用于 GitHub 更新检查、手动检查后的自动下载和用户选择的更新下载。

### 附件

| 文件 | 用途 |
|---|---|
| `WordCards-v*.apk` | 首次安装、完整更新和差分回退 |
| `WordCards-旧版本号-to-新版本号-来源哈希.wcdiff` | 当前旧 APK 到新版的差分数据 |
| `update.json` | 应用读取的版本、文件大小和 SHA-256 清单 |

学习记录保存在手机应用私有目录，未包含在安装包内。

卸载应用会清除学习记录。
