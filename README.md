# 逐词卡 · Android 更新

逐词卡的公开下载和应用更新仓库。这里只发布 APK、差分包、校验值和更新清单；开发源码和签名私钥保留在本地。

## 安装

在 [最新版本](https://github.com/julibeian/wordcards-releases/releases/latest) 下载 `WordCards-v版本号.apk`，打开并按 Android 系统提示安装。支持 Android 8.0 及以上版本。

v1.5.0 及更早版本需要先手动覆盖安装一次带有更新器的新版本。覆盖安装会保留星标和当前学习进度，请勿卸载旧版。

## 后续更新

在查词或自查页面底部的 **⋮ → 应用更新** 中检查更新。默认每天自动检查一次，也可以关闭自动检查。

- 有与当前安装包精确匹配的差分包时，优先下载差分包。
- 词典和图片没有变化时，复用其压缩内容，只下载变化部分。
- 应用将差分包还原为完整新版 APK，校验大小、SHA-256、应用包名、版本号和原签名后，再交给 Android 系统安装。
- 系统仍需用户确认安装。差分包不能直接作为 APK 打开。
- 找不到匹配的差分包时显示完整包下载大小；差分失败后可重试或手动选择完整包。

查词和自查仍可离线使用。网络仅用于 GitHub 更新检查和用户选择的更新下载，无需 GitHub 登录，不上传学习记录。

## 发布附件

| 文件 | 用途 |
|---|---|
| `WordCards-v*.apk` | 首次安装、完整更新和差分回退 |
| `WordCards-旧版本号-to-新版本号-来源哈希.wcdiff` | 当前旧 APK 到新版的差分数据 |
| `update.json` | 应用读取的版本、文件大小和 SHA-256 清单 |
| `SHA256SUMS.txt` | 手动校验发布附件 |

APK 和附件可公开下载。学习记录保存在手机应用私有目录，未包含在安装包内。卸载应用会清除学习记录。
