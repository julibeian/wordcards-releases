# Android 应用下载

本仓库发布逐词卡和专注守护的安装包及应用内更新附件。

## 专注守护 Android app

[下载专注守护 v1.0.2](https://github.com/julibeian/wordcards-releases/releases/tag/focusguard-v1.0.2)，支持 Android 8.0 及以上版本，全中文界面。

- 底部只有「主页面」「数据」两栏，设置收进主页右上角齿轮。
- 主页面是卡片式专注空间：番茄专注 25 分钟、深度专注 45 分钟、禅定 30 分钟、休息 5 分钟，也可自定 1–180 分钟；进行中可暂停或结束。
- 数据页：今日应用时长分布、近七天使用与专注趋势、近三十天专注热力图、最近专注记录。
- 专注与禅定期间，分心应用的通知会被撤下，通知栏、锁屏和横幅都看不到，也不能从通知直接回复；电话、闹钟和系统通知不受影响。
- 每日应用限额、分心清单、禅定白名单；记录仅保存在本机，不读取屏幕文字或聊天内容，无需账号。
- 首次在“设置”开启使用情况访问、无障碍应用拦截和通知使用权；前两项决定能不能拦住界面，通知使用权决定能不能拦住消息本身。Android 13 及以上若无障碍开关受限，请先在系统应用信息右上角允许受限设置。
- 在“设置 → 应用更新”检查新版，采用与逐词卡 v1.7.2 一致的差分还原、断点续传、文件与签名校验、系统安装确认；已有匹配的旧包时优先下载差分包。

专注守护使用独立的 `focusguard-latest/FocusGuard-update.json` 更新通道。逐词卡原来的 latest 更新入口继续保留。普通 Android 应用不具备厂商系统级的强制锁定权限；电话、桌面、系统设置与紧急功能始终保留。

## 逐词卡Android app

逐词卡app的应用下载和更新仓库。

### 安装

在 [最新版本](https://github.com/julibeian/wordcards-releases/releases/latest) 下载。支持 Android 8.0 及以上版本。


### 更新

在背词页底部点 **应用更新** 可立即联网确认；更新页内也有“立即检查更新”。默认每天自动检查一次，也可以关闭自动检查。

- 手动检查后有新版本会立即自动下载；网络中断时从已下载的位置续传，反复中断会提示稍后继续，不会从头重下。没有新版本时显示“无更新”。
- 有与当前安装包精确匹配的差分包时，优先下载差分包。
- 词典和图片没有变化时，复用其压缩内容，只下载变化部分。
- 应用将差分包还原为完整新版 APK，校验大小、SHA-256、应用包名、版本号和原签名后，再交给 Android 系统安装。
- 找不到匹配的差分包时显示完整包下载大小；差分失败后可重试或手动选择完整包。

查词和自查离线使用。网络用于 GitHub 更新检查、手动检查后的自动下载和用户选择的更新下载。

### 附件

| 文件 | 用途 |
|---|---|
| `WordCards-v*.apk` | 首次安装、完整更新和差分回退 |
| `WordCards-旧版本号-to-新版本号-来源哈希.wcdiff` | 当前旧 APK 到新版的差分数据 |
| `update.json` | 应用读取的版本、文件大小和 SHA-256 清单 |

学习记录保存在手机应用私有目录，未包含在安装包内。

卸载应用会清除学习记录。
